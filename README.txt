THE HOLLOW NIGHT - 11 minute narrated horror short film (HTML5 canvas + Web Audio + speech narration)

RUN IN VS CODE
1. Unzip, File > Open Folder > horror-movie
2. Install the "Live Server" extension, right-click index.html > Open with Live Server
   (double-clicking index.html also works)
3. Use Chrome or Edge (best narration voice). Click BEGIN. Headphones + dark room.

CONTROLS: Space pause | R restart | 1-9 jump to chapter | F fullscreen | M mute narration+sound
CHAPTERS: 1 The Letter, 2 The Gate, 3 The Graveyard, 4 The House, 5 The Hallway, 6 The Mirror, 7 The Child's Room, 8 Found Footage, 9 The Television
EDIT: story lines are in the NL array in js/main.js; chapter lengths are the D array at the top.
